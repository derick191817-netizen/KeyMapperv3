ABRIR NO ANDROID STUDIO
-----------------------
1. Extraia o ZIP inteiro para uma pasta.
2. No Android Studio, use File > Open e selecione a pasta extraída (a que contém
   settings.gradle.kts e gradlew).
3. Aguarde a sincronização do Gradle com acesso à internet.
4. Use JDK 17. O projeto declara compileSdk 34, NDK 26.3.11579264 e CMake 3.22.1.
5. Não copie o conteúdo para dentro de uma subpasta adicional nem abra somente app/.

COMPILAR APK DEBUG
------------------
Linux/macOS/GitHub Actions:
  chmod +x ./gradlew
  ./gradlew --no-daemon :app:assembleDebug

Windows:
  gradlew.bat --no-daemon :app:assembleDebug

Validar antes do APK:
  ./gradlew --no-daemon :app:lintDebug
  ./gradlew --no-daemon :app:testDebugUnitTest

Saída esperada, somente após build bem-sucedido:
  app/build/outputs/apk/debug/app-debug.apk
