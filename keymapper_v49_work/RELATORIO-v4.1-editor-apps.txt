RELATÓRIO TÉCNICO — KeyMapper v4.1

Base: KeyMapper v4.0.

Escopo implementado
1. Editor visual: nova MappingEditorScreen.kt com área de referência 16:9, grade, seleção, arrasto, criação de tecla/tiro/mira, propriedades, validação básica de códigos, exclusão, descarte e salvamento.
2. Persistência: o editor grava a lista HudButton através de SettingsViewModel; os botões continuam serializados pelo modelo existente.
3. Aparência independente: HudButton.visualScale é opcional no JSON e assume 1.0 quando ausente; HudView usa essa escala na renderização.
4. Aplicativos: aba Apps descobre aplicativos com launcher activity, oferece busca, permite mostrar apps de sistema e selecionar múltiplos pacotes.
5. Migração: AppSettings.fromJson deixou de filtrar games por DEFAULT_GAMES; pacotes legados são preservados e strings vazias são descartadas.
6. Rotação AUTO: a lista de heurística 3D inclui alguns pacotes populares adicionais. Isso só afeta a escolha entre rotação Infinito e Centro; não é uma lista permitida de aplicativos.
7. Navegação: novo botão no painel inicial abre o editor.

Limitações restantes
- Os aplicativos selecionados compartilham as configurações e o layout global; perfis independentes por app ainda precisam de uma camada de perfis no modelo e no motor.
- Editor ainda não tem zoom/pan, desfazer/refazer, redimensionamento por alça nem fluxo de captura física de teclas.
- A área de referência não é uma captura ao vivo.
- O tamanho base do controle continua fazendo parte do modelo funcional legado; visualScale é a nova propriedade separada para apresentação.
